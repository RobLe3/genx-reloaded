# Workflow and outputs

The workflow begins with the user's request and energy level. A full journey is available; an urgent rewrite should not trigger a compulsory interview about the candidate's entire life.

| Stage | Input | Work | Useful output |
| --- | --- | --- | --- |
| Route | Request, urgency, supplied files | Choose support, audit, rewrite, research, or end-to-end scope | Smallest useful plan or immediate draft |
| Support, optional | Candidate's own memory or concern | Acknowledge emotion; ask one to three fitting prompts | A possible strength confirmed by the person |
| Establish facts | CV, notes, artifacts, explicit corrections | Separate supported, user-stated and unresolved claims | Compact evidence record |
| Map the target | Actual advertisement or provisional role direction | Distinguish mandatory, preferred, unclear and missing requirements | Requirement-to-evidence map |
| Recover depth | Relevant historical examples | Preserve original dates and translate capabilities faithfully | Keep, compress or omit decisions |
| Write | Confirmed evidence and target | Build positioning, first-page message, chronology and bullets | Usable CV and requested supporting copy |
| Inspect | Final copy and any requested files | Compare facts, inspect the opening, render and check extraction where possible | Specific readiness note |
| Continue | Candidate's chosen next step | Review forms, draft outreach, rehearse an example, or debrief rejection | One practical action or a brief handover |

## Three separate outputs

1. **Application copy:** clean, factual text without unresolved placeholders or private coaching notes.
2. **Review notes:** material gaps, consequential questions, retained historical value, and actual checks.
3. **Optional handover:** target, preferences, supported evidence, unresolved questions, version, and next action. Keep it private.

Do not flood a person requesting a two-page CV with ten pages of methodology. Detailed evidence maps can stay in working notes unless an audit is requested.

## Readiness

- **Draft, factual questions open:** a fact that affects the content remains unresolved.
- **Content reviewed, requested file checks pending:** content is usable, but a requested file check is unfinished.
- **Ready for candidate review, listed checks completed:** the requested scope is complete and the person can review it.

For text-only work, file rendering and extraction are outside scope. No label means employer acceptance, legal eligibility, or an ATS pass.

## Human choice remains central

The candidate chooses target roles, disclosure of private information, tone, desired responsibility, and whether to pursue a genuine qualification gap. A lack of a preferred tool is not a reason for the agent to prohibit applying. Factual questions still require truthful answers.
