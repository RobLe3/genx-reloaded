# PageUp

Checked 12 October 2026. Scope: vendor's [applicant FAQ](https://www.pageuppeople.com/faqs/).

**Documented:** Employers determine the application form. Existing profiles are associated with the organisation and email address. The FAQ directs application-process/status questions, inaccessible old-email accounts, and personal-data access/deletion requests to the hiring organisation. It also describes optional Google Drive document upload permissions.

**Help the candidate:** Start at the employer's verified careers page and use its password-recovery route. If the old email is inaccessible, draft a request to the organisation to restore access or provide an alternative. For a public-service or university role, review each supporting statement and selection-criteria field as well as the resume. Check the selected job, saved draft and final receipt.

**Avoid:** Treating a PageUp account as universal across employers, sending status questions to the vendor as though it decides hiring, or assuming cloud-drive authorisation is required when local upload is offered. The FAQ suggests another email in one recovery situation; prefer employer-assisted recovery before risking duplicate applications or losing continuity. Do not create duplicate identities to evade screening.

No parser specification, ranking model or universal file limit was verified here. Read the current vacancy and portal instructions for those particulars.
