# Oracle Taleo Enterprise

Checked 12 October 2026. **Version-limited evidence:** Oracle's [23D Application Flow Blocks](https://docs.oracle.com/en/cloud/saas/taleo-enterprise/23d/otcug/r-applicationflowblocks.html). This is older release documentation, not a claim about every current tenant.

**Documented in 23D:** Application flows can contain distinct resume-upload/parsing, attachment, plain-text resume, work-history and questionnaire blocks. General-profile and job-submission flows are distinct; configured Resume Content behaviour can affect general-profile updates. Job-submission and general-profile thank-you pages are separate blocks.

**Help the candidate:** Use the visible field purpose. If both an attachment and text/history are requested, complete both accurately. Review dates and resume designation where shown. Check that the confirmation names the job, rather than only a saved general profile. Keep a local copy of long answers before continuing through pages.

**If blocked:** Identify the current employer's instructions and release-relevant help before promising update or reapplication behaviour. Draft a request to correct the existing submission when uncertain.

**Avoid:** Assuming 'Taleo' means Oracle Fusion Recruiting, that an uploaded PDF fills all fields, or that updating a general profile replaces every submitted document. Do not recycle old integration limits, word limits or scoring folklore as current universal facts.
