# Workday Recruiting

Checked 12 October 2026. Scope: public administrator-training documentation, not every employer's tenant.

**Documented:** [Prospects and Candidates](https://doc.workday.com/workday-education/en-us/course-manuals/recruiting-for-administrators/prospects-and-candidates.html), External Job Applications and Candidate Home sections, describes resume-derived fields, reuse of a previous application, configurable account requirements and candidate tasks. It also describes suggested skills and, when configured, Candidate Skills Cloud scoring. Status labels and notification delays can be configured.

**Help the candidate:** Start at the correct employer's careers portal. Before submission, compare the chosen resume with reused work history, education, languages and suggested skills; remove inaccurate suggestions and correct editable fields. Check Candidate Home for outstanding tasks and actual application status. Save a receipt and the submitted version privately if wanted.

**If blocked:** Use that portal's recovery/help route. For an incorrect submitted file, ask about the employer's correction process rather than assuming a profile upload replaces it. Preserve a draft before browser troubleshooting.

**Avoid:** A universal 'Workday score', a guaranteed keyword threshold, claiming all tenants enable scoring, or treating a label as proof that a human has read the CV. Do not use another employer's account workflow as evidence for this tenant. Public training material may lag a release; verify the observed screen and current help when behaviour matters.
