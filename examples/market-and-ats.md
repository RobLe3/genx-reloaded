# Country and ATS examples

Fictional situations illustrating the 0.4.0 routes. These are editorial examples, not live ATS results or achievements to copy into a real CV. See the [catalogue](../evals/catalogue/cases.json) and [validation](../docs/validation.md) for the separately recorded executions.

| Situation | Useful response |
| --- | --- |
| US federal applicant has a six-page legacy resume | Check current USAJOBS/OPM requirements; preserve qualifying evidence, accurate dates and hours within the documented limit |
| Belfast applicant asks about age concerns | Draft the CV and route procedural research to Northern Ireland rather than assume one UK process |
| Montreal Workday form invents a degree and fluent French | Restore the original vocational award and actual language levels; check the vacancy's bilingual requirement |
| Australian APS applicant has community experience | Write the requested pitch using real coordination/communication examples; complete separate CV and application fields |
| NZ Recruitee submission picks a referee's email | Preserve confidentiality; request correction and separate supporting documents where the employer permits |
| Workable interview is already scheduled when an old file is discovered | Request an update that preserves the invitation; do not automatically withdraw |
| SuccessFactors custom fields remain blank | Check documented field limitations and correct editable data before redesigning the CV again |
| Personio applicant worries about inferred information | Preserve identity and chronology; ask about inaccurate derived data and the employer's process |

For example, a correction draft can say: 'I remain interested in the role and would like to keep my scheduled interview. An earlier cover letter was included in my application. Could you advise how I can replace it without withdrawing my application?'

Only say a revised file is attached when it actually is. Keep job references and private details out of reusable examples. The candidate chooses whether to send any draft.
