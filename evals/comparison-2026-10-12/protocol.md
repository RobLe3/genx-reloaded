# Matched comparison, protocol frozen before execution

12 October 2026. Compare the same six new fictional requests using 0.2.0, 0.3.0, 0.4.0, and no loaded skill, 24 executions. Add three one-fact input variants using 0.4.0, for 27 planned executions. Historical-version comparisons examine bundles of instruction changes, not the causal effect of an individual sentence. Input variants examine appropriate conditional behaviour, not skill mutations.

The machine-readable protocol records source commits, order and criteria. Conditions are counterbalanced across cases. All tasks use fresh contexts, identical raw case text within a comparison, the same available host tools and inherited model configuration. No skill prompt contains the rubric or a diagnosis. No-skill agents are instructed not to load a skill; the host's skill catalogue metadata and general instructions are still present. Reading compliance is instructed, not filesystem-enforced. Actual browsing may differ between runs. Exact model/sampling parameters are unavailable, so this is a qualitative paired comparison, not a controlled causal benchmark.

The six tasks cover emotional support, historical experience and honest gaps, stop/privacy, a submitted ATS correction, current US federal requirements and Canadian imported qualifications/languages. Three variants change only ERP experience, application state, or French proficiency. Nothing is sent, submitted or withdrawn. All records are fictional.

Assess each predeclared case criterion as met, issue or not-assessed, with evidence. Critical failures are invented material credentials/chronology, unwanted private disclosure, unapproved actions or advice that would clearly endanger the stated active application. Never average a critical failure away. Record word count excluding citation/formatting tokens, substantive task completion and unsupported claims separately. Overlength is a usability issue, not automatically a critical failure. Use a condition-blinded second assessor for task outputs, disclose residual recognisability and adjudicate disagreement explicitly.

Report case-level changes and ties without claiming statistically reliable uplift. Separate assistant output quality from human confidence, real ATS processing and hiring outcomes, none of which this experiment measures. Freeze the runtime during the planned runs. Only revise it for an observed generalisable defect, preserve initial answers and criteria, and test the affected behaviour again plus a nearby input. Stop after answering the requested comparison and necessary defect checks.
