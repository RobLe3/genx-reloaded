# Changelog

## 0.2.0, 12 October 2026, research preview

- Renamed the project and skill to GenX Reloaded, invocation `$genx-reloaded`.
- Added host-independent fallbacks, explicit conflict handling, application decisions, readiness labels, and a bounded improvement loop.
- Expanded guidance on bilingual applications, vocational qualifications, private career breaks, confidential work, and moves from leadership to hands-on roles.
- Corrected two issues observed in a German/English task trial: requested explanations belong inside the cover letter, and text-only outputs do not leave file checks pending.
- Improved the offline helper: exclude directly hidden and deleted Word text, observe style-hidden settings and explicit columns, avoid matching inside another word, and reject input/output hard-link collisions.
- Expanded synthetic tests from 8 to 15 and added inspectable task prompts and response records.
- Added installation, workflow, quality, privacy, versioning, worked-example and repository-validation documentation.

## 0.1.0, 12 October 2026, internal working baseline

- Created the GenX ATS CV workflow, optional strengths coaching and evidence register.
- Added the offline document checker and 8 synthetic tests.
- Conducted two qualitative task trials. Summaries are retained in the validation record; raw outputs were not included in the standalone repository.

The earlier CV Refresh prototype is historical context, not a separate maintained runtime in this repository.
